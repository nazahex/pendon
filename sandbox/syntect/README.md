# Syntect Sandbox

This sandbox demonstrates build-time codeblock highlighting using the syntect plugin, rendered to minimal HTML tags (<b>/<em>/<i>/<u>/<s>/<mark>) as per RFC.

## How to run

1. From this folder:

```bash
cd sandbox/syntect
cargo run --manifest-path ../../apps/cli/Cargo.toml -- run
```

This uses the local `pendon.toml` to produce HTML under `./static`.

2. Optional: open the HTML files and include `styles.css` in your page/app to see themed colors.

## Files

- `pendon.toml`: config with `plugin = "markdown,syntect"`, `format = "html"`.
- `content/*.md`: example Markdown with code fences (rust, js, python, plain).
- `static/*.html`: outputs generated by `pendon run`.
- `styles.css`: minimal CSS theme mapping minimal tags to colors.
